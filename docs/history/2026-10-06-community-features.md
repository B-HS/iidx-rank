# 커뮤니티 기능·공용 셸·UI/UX 감사

사용자가 workflow 사용과 Fable 미사용을 명시했습니다. main은 Opus, 하위는 Opus(셸 재구성, 프로필, 게시판 서버·화면, UI/UX 감사, 오류 코드·문구 수정)와 Sonnet(조사, 스키마·의존성, R2 파일 API, 계정 전환 동기화 이동, 통합 브라우저 검증, 접근성·메타데이터 수정)으로 배정했습니다.

## 결과

- 요청 1·2 사용자 페이지와 공개/비공개: /u/<핸들>(사진, 닉네임, @핸들 · 팔로워 수 · 플레이한 보면 수, 소개, 팔로우, 탭 레지스트리), /settings(닉네임, 핸들, 소개, 사진 업로드, 공개 스위치, 차단 목록).
- 요청 3 홈: 사이드바 홈 메뉴와 대시보드 빈 상태(/). 난이도표는 /table로 이동.
- 요청 4 최근 갱신 사용자: 공개 프로필 중 기록 갱신 시각순 10명을 사이드바에 표시.
- 요청 5 램프 깜빡임: 주기 1200ms → 600ms.
- 요청 6 DP: 원본 스프레드시트(☆12参考表)에 DP 표가 없어 사용자 결정으로 제외.
- 요청 7 게시판: 글·댓글·공지(관리자 CRUD, 상단 고정)·페이징, tiptap 에디터와 본문 이미지(R2), 서버 측 본문 검증.
- 요청 8 사용자 이름 메뉴: 프로필 보기(공개일 때)와 차단, 설정에서 해제.
- 요청 9 디자인 문서와 UI/UX: docs:/DESIGN.md 삭제(내용 동일), 감사 후 즉시 적용 23건 반영, 보고만 16건 기록.

## 검증

- 정적: typecheck 0, lint 오류 0(경고 4: 기존 캐시 키 인자 3, 본문 img 1), 테스트 87 pass.
- 서버 로직: 임시 SQLite에서 마이그레이션 23개, 프로필 56개, 게시판 87개와 라우트 헬퍼 20개 단언 일치. R2 왕복(저장·조회·삭제) 성공.
- 브라우저 통합 검증: 임시 SQLite와 로컬 주소로 9개 흐름 합격(가입·로그인·로그아웃, 프로필 설정과 사진, 팔로우, 최근 목록, 글·댓글·공지·페이징, 이름 메뉴와 차단, 390px, 다크 테마). R2에 테스트 이미지 2개 업로드.
- UI/UX 수정분: 빌드 통과, 페이지별 문서 제목과 없는 파일 조회 응답을 로컬 서버로 확인. 그 밖의 시각 항목은 브라우저 미확인.
