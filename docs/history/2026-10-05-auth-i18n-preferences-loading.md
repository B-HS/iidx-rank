# 가입·다국어·비로그인 설정·로딩 개선

대상: src/app/[locale], src/shared/i18n, src/shared/messages, 인증 오류·출처, 표시 설정, CheckerWorkspace·로딩 컴포넌트

## 변경

- 가입 실패의 실제 원인인 커스텀 도메인 출처 거부를 수정하고 오류별 안내를 적용했습니다.
- KO/JP/EN과 언어 선택·저장, ICU 카운트, 번역된 폼 검증·알림·접근성·Tokyo 기준 날짜를 적용했습니다.
- 비로그인 로고/시리즈명·불투명도를 브라우저에 저장·복원하고 계정의 DB 설정과 분리했습니다. 쿠키와 localStorage가 다를 때 서버가 사용한 유효 쿠키를 우선해 첫 화면과 일치시킵니다.
- 실제 랭크별 지력/개인차 개수와 동일한 반응형 열 수·빈 셀·구간 높이로 스켈레톤을 렌더링합니다. 표시 방식이 아직 확인되지 않았거나 개인 필터 결과를 모르는 경우 고정된 표 영역을 사용합니다.
- 로고/시리즈명 카드 본문은 각각 40/56px, 중립 격자 경계를 포함한 실제 카드는 42/58px입니다. 로고 모드의 DJ 랭크 자리도 항상 예약합니다. 헤더 48px, 그룹 헤더 24px, 원본 정보·진행률 행 높이를 공유합니다.
- 서버에서 확인한 표시 설정은 세션 재확인 중 유지하고 개인 램프/DJ 랭크만 대기 표시합니다. 인증 새로고침 버튼은 헤더 앞쪽에 배치해 기존 필터/카운트 위치를 유지하며, 하단 계정/테마 텍스트 영역을 고정해 스켈레톤에서 아이콘 위치가 달라지지 않게 합니다.
- 설정 모달의 로고 슬라이더는 실측에서 확인된 10px 차이를 제거했습니다. 로고 설정 본문 148px, 시리즈명 96px로 로딩과 실제 높이가 같습니다.
- 정적 표의 DB 조회 전체를 getCatalogForShell의 use cache 안에 넣었습니다. 기존 catalog 태그·5분 재검증·1시간 만료를 사용하며 원본 갱신의 expire:0 태그 무효화가 정적 표에도 적용됩니다. 세션·쿠키·UUID 데이터는 별도 Suspense와 기존 사용자 캐시를 유지합니다.

## 검증

- 분리 환경 bun run build 성공: ko/ja/en은 Partial Prerender, Cache Components·React Compiler 유지, catalog 5분/1시간, 개인 API 동적 유지.
- 위험 경계 6개 테스트 18 assertions 성공. 이후 인증 상수 정리의 관련 인증 3개 테스트 7 assertions 및 타입 검사 성공. 새 로직의 ESLint 오류/경고 0. catalog.server.ts의 기존 _generation 미사용 경고 1건은 Cache Components의 자동 캐시 키 인자를 유지하기 위해 변경하지 않았습니다.
- 3개 언어 196개 공통 메시지의 1,176개 ICU 포맷 호출에서 누락/문법 오류 0. 알림 접근성·인증 실패의 중립적 안내도 포함합니다.
- 로컬 임시 계정 가입/로그인·세션·중복·비밀번호·다른 출처·설정 저장 확인. 영어 중복 이메일 안내, JP 전환 및 KO/JP/EN 렌더링, 루트 재접속의 EN 선택 유지 확인.
- 비로그인 시리즈명 새로고침 유지, 로고 15% 저장/복원, 로그인 시 DB 시리즈명 설정 및 로그아웃 시 비로그인 로고로 복귀 확인.
- 1280px와 390px에서 전체 10개 랭크 구간의 실제/스켈레톤 높이 차이 0. 모바일 3열·가로 넘침 0. 설정 본문도 148/96px로 동일합니다.
- 별도 QA 프록시에서 동적 스트림 청크를 500ms씩 지연하고 렌더 전 PerformanceObserver를 주입했습니다. 첫 화면부터 약 2.3초 후 실제 표까지 데스크톱/모바일·로고/시리즈명·인증된 사용자 케이스의 unexpected layout-shift 목록은 비어 있습니다. 초기 로딩 실험의 CLS는 0이며 모든 실제 사용자 환경을 보증하는 수치는 아닙니다. 기준: https://web.dev/articles/cls
- 검증 프록시·비교 페이지·관찰 코드는 분리 환경에만 있으며 저장소 및 배포에 포함하지 않습니다. 운영 인증 검사는 계정을 만들 수 없는 입력으로만 수행합니다.
