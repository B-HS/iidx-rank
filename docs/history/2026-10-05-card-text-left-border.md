# 카드 글자 배경과 난이도 테두리 수정

## 요청과 대상

사용자 지시에 따라 src/features/chart-card-grid/chart-card.tsx의 곡명·시리즈명·DJ 랭크 배경 유틸리티를 제거했습니다. 기존 배경은 로고 위 글자 가독성을 위한 것이었으나 사용자가 요청한 디자인과 맞지 않았습니다.

src/app/globals.css의 난이도 색상 테두리는 왼쪽 2px만 적용합니다. 다른 방향은 중립색 1px 격자 경계를 유지하며, 별도의 5px 클리어 램프는 기존 위치와 점멸 동작을 유지합니다. 불투명도 설정과 게이지 입력 동작은 변경하지 않습니다.

## 검증

- .env 없는 검증 복사본에서 Next build 및 TypeScript 통과, 변경 두 파일 Prettier 통과. 스타일 변경이므로 별도 동작 테스트를 추가하지 않았습니다.
- 데스크톱 1280px: 6열, document width 1280px. A/L 카드 왼쪽 2px 빨강/보라, 나머지 방향 1px 중립색 확인.
- 카드 글자 span의 backgroundColor는 rgba(0,0,0,0). 램프 너비 5px, 카드 왼쪽 경계로부터 2px 안쪽에 있어 난이도 테두리와 겹치지 않습니다.
- 모바일 390px: 3열, document width 390px, 모든 그리드의 마지막 행 빈칸 유지 확인. 실제 모바일 화면도 확인했습니다.

운영 배포 결과는 완료 후 기록합니다.
