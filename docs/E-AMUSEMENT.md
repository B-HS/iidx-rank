# e-amusement 연동 예정

현재 범위에서는 연동하지 않습니다. 사용자 요청에 따라 향후 구현 계획만 기록합니다.

## 확인할 사항

1. 공식적으로 허용된 기록 API, 계정 인증 흐름, 접근 권한과 이용 조건을 조사합니다. 현재 공개 난이도표에는 사용자 플레이 기록이 없습니다.
2. 지원되는 내보내기 파일 또는 사용자가 제공한 기록을 가져오는 방식도 비교합니다. 공식 제공 경로가 확인되기 전 자동 로그인이나 비공개 API를 가정하지 않습니다.
3. 게임의 안정된 곡·패턴 ID와 이 앱의 chartId를 대응시킵니다. 곡명 NFKC 정규화만으로 동일 곡임을 보장하지 않습니다.
4. 게임 램프와 자체 램프 매핑, 플레이 버전·삭제곡·미결정곡, 재수집 시 개인 메모 보존 정책을 확정합니다.
5. 토큰·쿠키는 서버에서만 보관하고 사용자별 연결 해제와 데이터 삭제를 제공하도록 설계합니다.

## 캐시와 기록 병합

- 외부 동기화와 난이도표 동기화를 구분합니다.
- 인증된 사용자의 UUID로 연결과 기록을 분리합니다.
- 기록 반영과 revision 증가는 하나의 트랜잭션으로 처리하고 사용자 태그를 즉시 만료합니다.
- 수동 기록과 외부 기록이 충돌할 때 덮어쓰기 정책을 합의합니다. 개인 메모는 유지합니다.
- 다중 서버 배포 시 Next 캐시 저장소·태그 전파, Turso 접속과 인증을 별도 검증합니다. 로컬 단일 서버 검증을 배포 검증으로 간주하지 않습니다.
